# Bai tap Python - Loi giai De so 01 va De so 02

Repository gom loi giai tham khao cho ca ba nhom de trong file ZIP: **CBPYTHON**, **NCPYTHON** va **NDPYTHON**.

## Cau truc

- `CBPYTHON/de_so_01.py`, `CBPYTHON/de_so_02.py`: moi de gom cac cau 1-5.
- `NCPYTHON/de_so_01.py`, `NCPYTHON/de_so_02.py`: moi de gom cac cau 1-3.
- `NDPYTHON/de_so_01.py`, `NDPYTHON/de_so_02.py`: loi giai theo noi dung PDF (De 01 khong co Cau 3 trong de goc).

## Cach chay

Can Python 3.10 tro len, khong can cai them thu vien.

Mo terminal tai thu muc repository va chay mot file, vi du:

```bash
python CBPYTHON/de_so_01.py
python CBPYTHON/de_so_02.py
python NCPYTHON/de_so_01.py
python NCPYTHON/de_so_02.py
python NDPYTHON/de_so_01.py
python NDPYTHON/de_so_02.py
```

Cac cau co `input()` can nhap du lieu theo huong dan tren man hinh. Voi cau nhap hai so, nhap tren cung mot dong, cach nhau boi dau cach (vi du: `-5 10`).

## Luu y

- Cac cau duoc tach bang comment trong tung file de de doi chieu voi de bai.
- CBPYTHON De 01 Cau 1a ghi "so thuc" nhung yeu cau chan/le. Chan/le chi co nghia voi so nguyen; trong loi giai, so thuc nguyen duoc kiem tra theo gia tri nguyen, so khong nguyen duoc quy uoc la "Le". Neu giao vien co quy uoc khac, can dieu chinh theo yeu cau tren lop.
- Cac ket qua cua set co the hien thi theo thu tu khac nhau, vi set khong bao dam thu tu.
- Day la loi giai tham khao de hoc va tu kiem tra, khong phai ket qua cham diem chinh thuc.
